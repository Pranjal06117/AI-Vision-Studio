
# AI Vision Studio

A multi-module image classification and processing application developed using Python, TensorFlow, MobileNetV2, OpenCV and Streamlit.

## Features

- Animal Classification: Cat vs Dog
- Waste Classification: Nine waste categories
- Multi-Angle Image-to-Sketch Studio

## Technologies

- Python
- Streamlit
- TensorFlow
- MobileNetV2
- OpenCV
- NumPy
- Pillow
- Scikit-learn

## Project Structure

```text
AI_Vision_Studio/
├── app.py
├── requirements.txt
├── README.md
├── modules/
├── models/
└── .gitignore
```

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

## Models

The application uses trained animal and waste classification models stored in the models directory.
